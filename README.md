# E-Commerce Gamer

Proyecto final de JavaScript. Tienda online (simulada) de productos gamer: juegos físicos, periféricos, consolas e insumos de PC.

## Tecnologías
- HTML5 / CSS3
- JavaScript (Vanilla)
- Toastify.js (notificaciones)
- SweetAlert2 (confirmaciones y alertas)

## Funcionalidades
- Carga de productos vía fetch desde productos.json
- Filtro por categoría y buscador combinables
- Carrito de compras con localStorage (agregar, eliminar, vaciar)
- Simulación de checkout

## Cómo correrlo
Clonar o descargar el repo y abrir index.html en el navegador (recomendado usar Live Server para evitar problemas de CORS con el fetch).
